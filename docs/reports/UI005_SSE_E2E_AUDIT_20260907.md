## 5. 结论与剩余事项

### 已确认

1. backend 的 SSE/replay 约束在本批选定的 40 项测试中通过。
2. frontend 的 SSE transport、Run stream lifecycle、gap repair 和 reducer 在 52 项定向测试中通过。
3. 现有实现已经有游标续接、终态停连、重试耗尽、重复事件去重和 late-history generation fence 的单测证据。
4. 本批没有产生 backend 修改。

### 尚未证明

1. **浏览器端 fresh E2E 尚未证明**：由于 5174 端口已有 Node listener，Playwright 在 webServer 启动前退出。
2. **真实长运行 browser stream 尚未证明**：现有 fixture 使用 route.fulfill 的静态 SSE body/空 body，未形成真实持续写入、自然中途断线、带浏览器网络层重连的 fresh 结果。
3. **浏览器端重复事件未证明**：reducer 单测证明逻辑去重，但页面级 duplicate replay 没有 fresh E2E 证据。
4. **live payload 的多 Run run_id 错配未证明**：当前 `useAgentRunStream` 代码对 live payload 仅执行 generation/activeRunId fence，没有显式的 `payload.run_id === options.runId` 校验。后续前端修复批应增加该 guard 和 browser fixture；本批按要求停止扩展，没有改 frontend。
