### Learnings for Future Iterations

#### Codebase Patterns Discovered

1. **Quality Gate Summary Structure**
   ```python
   {
       "passed": bool,
       "tone": str ("success" | "warning" | "danger"),
       "count": int,
       "codes": [str],
       "labels": [str]
   }
   ```

2. **Allowed Actions Protocol**
   - Success → `["publish", "download"]`
   - Failure → `["retry", "abort"]`

3. **Violation Severity Hierarchy**
   - CRITICAL > MAJOR > MINOR
   - CRITICAL stops generation, allows retry
   - MAJOR warns but may allow continue
   - MINOR cosmetic suggestions only
